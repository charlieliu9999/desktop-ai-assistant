# 🚀 Bisheng 智能体集成 - 快速开始

> 本指南帮助你快速设置和使用桌面 AI 助手的 Bisheng 智能体功能

## 📋 前置要求

- ✅ macOS 系统
- ✅ Docker Desktop 已安装并运行
- ✅ Node.js 和 npm 已安装
- ✅ Python 3.8+ 已安装

## 🎯 三步快速开始

### 第一步: 启动所有服务

```bash
cd desktop-ai-assistant

# 给脚本添加执行权限 (首次运行)
chmod +x start-all-services.sh stop-all-services.sh check-services.sh

# 启动所有服务
./start-all-services.sh
```

**预期输出**:
```
✓ Bisheng 后端服务启动成功 (http://localhost:7860)
✓ Bisheng 前端服务已在运行 (http://localhost:3001)
✓ 桌面助手后端服务启动成功 (http://localhost:8000)
```

### 第二步: 启动桌面应用

在**新终端**中运行:

```bash
cd desktop-ai-assistant
npm run dev
```

### 第三步: 配置并测试

1. **打开设置面板**
   - 点击应用右上角的设置图标 ⚙️
   - 选择 "智能体设置"

2. **查看连接状态**
   - 顶部会显示实时连接状态指示器
   - 🟢 绿色 = 已连接并认证
   - 🔴 红色 = 未连接

3. **填写配置**
   ```
   ✓ 启用智能体服务: [勾选]
   API 地址: http://localhost:7860
   前端地址: http://localhost:3001
   用户名: lzhy9999@163.com
   密码: Moto@9999
   ```

4. **测试连接**
   - 点击 "测试登录" 按钮
   - 应该看到: "连接成功! Token 已获取"
   - 点击 "完整测试" 验证所有功能

5. **保存配置**
   - 点击 "保存配置" 按钮

6. **开始使用**
   - 导航到 "智能体服务" 页面
   - 选择工作流
   - 开始与 AI 对话

## 🔧 故障排查

### 问题: 端口被占用

**症状**: 启动服务时提示端口已被占用

**解决**:
```bash
# 方案 1: 使用脚本自动处理
./start-all-services.sh
# 按提示选择是否杀死占用进程

# 方案 2: 手动查找并杀死进程
lsof -i :8000  # 查找占用端口 8000 的进程
kill -9 <PID>  # 杀死进程
```

### 问题: Bisheng 服务未初始化

**症状**: 点击测试按钮时提示 "Bisheng service not initialized"

**解决**:
```bash
# 1. 重新构建应用
npm run build

# 2. 重启应用
npm run dev
```

### 问题: 连接状态显示错误

**症状**: 状态指示器一直显示红色或检查中

**解决**:
1. 检查 Bisheng 服务是否运行:
   ```bash
   curl http://localhost:7860/api/v1/health
   ```

2. 点击状态指示器旁边的刷新按钮

3. 查看浏览器控制台错误信息 (F12)

### 问题: Docker 未运行

**症状**: 启动脚本提示 "Docker 未运行"

**解决**:
1. 启动 Docker Desktop
2. 等待 Docker 完全启动
3. 重新运行启动脚本

## 🎨 功能特性

### ✨ 连接状态指示器

- 🟢 **绿色**: 已连接并认证 - 可以正常使用
- 🟡 **黄色**: 已连接但未认证 - 需要登录
- 🔵 **蓝色**: 正在检查 - 请稍候
- 🔴 **红色**: 连接失败 - 检查服务状态
- ⚪ **灰色**: 服务未启用 - 需要启用

### 🔄 自动功能

- ✅ 自动检测端口冲突
- ✅ 自动处理服务启动
- ✅ 自动保存配置

### 🛡️ 安全特性

- ✅ 本地加密存储密码
- ✅ Token 自动管理
- ✅ 安全的 IPC 通信
- ✅ 配置文件权限保护
