# 测试指南

## 问题1：设置保存按钮修复

### 测试步骤

1. **启动应用**:
```bash
cd desktop-ai-assistant
npm run dev
```

2. **打开设置页面**:
   - 点击主窗口的设置图标
   - 或使用快捷键 `Cmd+,` (macOS) / `Ctrl+,` (Windows/Linux)

3. **测试保存功能**:
   - 修改任何配置项（例如：主题、语音设置等）
   - ✅ 应该看到"有未保存的更改"提示（黄色警告图标）
   - ✅ "保存设置"按钮应该是蓝色且可点击
   - 点击"保存设置"按钮
   - ✅ 应该看到"设置已保存"的成功提示
   - ✅ "有未保存的更改"提示消失
   - ✅ "保存设置"按钮变灰且不可点击

4. **测试持久化**:
   - 关闭应用
   - 重新启动应用
   - 打开设置页面
   - ✅ 之前保存的配置应该保持不变

5. **测试取消更改**:
   - 修改一些配置
   - ✅ 看到"有未保存的更改"提示
   - 不点击保存，直接刷新页面或关闭设置
   - ✅ 配置应该恢复到上次保存的状态

## 问题2：桌面识别对话统一管理

### 测试步骤

1. **启动应用**:
```bash
cd desktop-ai-assistant
npm run dev
```

2. **打开桌面识别页面**:
   - 在主窗口导航到"桌面识别"标签

3. **测试基础流程**:
   - 点击"一键开始"按钮
   - ✅ 应该看到系统消息："开始一键流程..."
   - ✅ 应该自动截图（如果配置了显示截图）
   - ✅ 应该看到患者信息识别结果
   - ✅ 应该看到AI推荐内容（流式输出）
   - ✅ 会话ID应该显示为 `desktop-{患者ID}`

4. **测试后续对话**:
   - 在输入框输入问题，例如："请详细说明诊断依据"
   - 按 Enter 键发送（或点击"发送"按钮）
   - ✅ 应该看到用户消息
   - ✅ 应该看到AI助手的流式响应
   - ✅ 消息应该自动滚动到底部

5. **测试键盘快捷键**:
   - 在输入框输入文本
   - 按 Enter 键
   - ✅ 应该发送消息
   - 按 Shift+Enter
   - ✅ 应该换行而不是发送

6. **测试持久化**:
   - 完成一次对话后
   - 刷新页面（F5 或 Cmd+R）
   - ✅ 对话历史应该保留
   - ✅ 会话ID应该保持不变

7. **测试清除功能**:
   - 点击"清除"按钮
   - ✅ 所有消息应该清空
   - ✅ 截图应该清除
   - ✅ 会话ID应该重置

8. **测试错误处理**:
   - 在没有患者信息时尝试发送消息
   - ✅ 应该不允许发送（按钮禁用）
   - 断开网络后尝试对话
   - ✅ 应该显示错误消息

## 如果遇到问题

### 问题1：保存按钮仍然灰色
**可能原因**: 缓存问题  
**解决方案**:
```bash
# 清除缓存并重新构建
cd desktop-ai-assistant
rm -rf node_modules/.vite
npm run dev
```

### 问题2：对话消息不持久化
**可能原因**: localStorage 被禁用  
**解决方案**:
1. 打开浏览器开发者工具（F12）
2. 检查 Console 是否有错误
3. 检查 Application > Local Storage 是否有数据

### 问题3：流式输出不显示
**可能原因**: API 配置错误  
**解决方案**:
1. 检查设置中的 AI 配置
2. 确保 API URL 和 API Key 正确
3. 检查网络连接

## 开发者调试

### 查看 Store 状态

打开浏览器开发者工具，在 Console 中运行：

```javascript
// 查看配置 Store
window.__ZUSTAND_STORES__ = window.__ZUSTAND_STORES__ || {};

// 查看对话 Store
import { useChatStore } from './src/renderer/stores/chatStore';
console.log(useChatStore.getState());

// 查看所有会话
console.log(useChatStore.getState().getAllSessions());
```

### 查看持久化数据

在开发者工具的 Application 标签：
1. 展开 Local Storage
2. 查看 `chat:sessions:desktop-{patientId}` 键
3. 查看存储的消息数据

## 智能体对话测试（新增）

### 测试步骤

1. **启动应用并打开智能体页面**:
   - 在主窗口导航到"智能体服务"标签

2. **测试问题1修复：首次对话不需要输入两次**:
   - 选择一个智能体
   - 等待自动启动完成（应该看到欢迎语或引导问题）
   - 输入第一个问题，例如："肝脏 平扫+增强 扫描参数"
   - ✅ 应该直接收到AI回复
   - ❌ 不应该看到"工作流已准备就绪，请继续输入..."的提示

3. **测试问题2修复：停止按钮功能**:
   - 发送一个问题
   - 在AI回复过程中点击"停止"按钮
   - ✅ 应该立即停止生成
   - ✅ 输入框应该重新可用（不再显示禁用状态）
   - ✅ 不应该显示错误消息
   - 继续发送新消息
   - ✅ 应该正常工作

4. **测试问题3.1修复：异步接收数据**:
   - 发送一个问题
   - 在AI回复过程中切换到其他智能体
   - 等待几秒
   - 切换回原来的智能体
   - ✅ 应该看到在后台接收的消息
   - ✅ 会话历史应该完整保留

5. **测试问题3.2修复：加载动画正确停止**:
   - 发送一个问题
   - 观察输入框右侧的按钮
   - ✅ 在AI回复过程中应该显示"停止"按钮（红色）
   - ✅ 收到完整回复后应该显示"发送"按钮（蓝色）
   - ✅ 输入框应该重新可用
   - 如果有很慢的智能体，测试60秒超时
   - ✅ 超时后应该显示错误消息
   - ✅ 加载状态应该停止

6. **测试切换智能体时的清理**:
   - 发送一个问题
   - 在AI回复过程中快速切换到另一个智能体
   - ✅ 之前的请求应该被自动取消
   - ✅ 新智能体应该正常自动启动
   - ✅ 不应该有状态混乱
