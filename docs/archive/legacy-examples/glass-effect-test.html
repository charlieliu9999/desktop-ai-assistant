📋 如何判断玻璃效果是否生效?

  • 卡片背景应该是半透明的,能看到背后的渐变色
  • 背景应该有模糊效果,不是清晰的渐变色
  • 颜色应该比对照组更鲜艳(饱和度增强)
  • 移动卡片时,背后的背景应该跟随模糊

💡 浏览器兼容性

  • Chrome/Edge 76+: 完全支持
  • Safari 9+: 需要 -webkit- 前缀
  • Firefox 103+: 完全支持
  • Firefox 70-102: 需要在 about:config 中启用

⚠️ 如果看不到玻璃效果,请尝试:

  • 更新浏览器到最新版本
  • 使用 Chrome、Edge 或 Safari
  • 检查浏览器是否启用了硬件加速
