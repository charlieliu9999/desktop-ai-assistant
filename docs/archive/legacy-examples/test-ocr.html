🤖 OCR功能测试页面

📋 使用说明

这个页面用于测试桌面AI助手的OCR（光学字符识别）功能。请按照以下步骤进行测试：

  1. 首先点击"检查配置"按钮，查看当前系统状态
  2. 如果桌面识别功能未启用，点击"启用桌面识别"按钮
  3. 点击"测试屏幕截图"按钮，测试截图功能
  4. 或者直接点击"运行完整测试"按钮，自动执行所有测试步骤

注意：此页面需要在桌面AI助手应用程序中打开才能正常工作。

检查当前应用程序的配置状态和API可用性。

📋 桌面识别控制

📸 屏幕截图测试

测试屏幕截图功能，验证是否能够正常捕获屏幕内容。
