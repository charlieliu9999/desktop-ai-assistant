# 患者信息识别功能使用指南

## 📋 功能概述

本功能通过屏幕截图和 Qwen2.5-VL 视觉AI模型,自动识别医生工作页面中的患者信息,并基于识别结果生成检查项目推荐。

---

## 🚀 快速开始

### 前置条件

1. **Ollama 服务运行**
   ```bash
   # 检查 Ollama 是否运行
   curl http://localhost:11434/api/tags
   
   # 如果未运行,启动 Ollama
   brew services start ollama
   ```

2. **Qwen2.5-VL 模型已安装**
   ```bash
   # 检查模型是否已安装
   ollama list | grep qwen2.5vl
   
   # 如果未安装,下载模型
   ollama pull qwen2.5vl:latest
   ```

3. **后端服务运行**
   ```bash
   cd desktop-ai-assistant/backend-service
   python -m app.main
   
   # 应该看到:
   # INFO:     Uvicorn running on http://0.0.0.0:8010
   ```

4. **桌面AI助手运行**
   ```bash
   cd desktop-ai-assistant
   npm run dev
   ```

---

## 📖 使用流程

### 步骤 1: 打开智能识别页面

1. 启动桌面AI助手
2. 点击"医疗系统"标签
3. 选择"智能识别"子标签

### 步骤 2: 准备患者信息页面

1. 打开医生工作页面 (medical-integration-system)
2. 确保患者信息清晰可见
3. 建议将患者信息区域放大

**推荐的患者信息格式**:
```
姓名: 张三
年龄: 45岁
性别: 男
患者ID: P20250103001
科室: 呼吸内科
主诉: 胸痛3天,伴有咳嗽
诊断: 疑似肺炎
现病史: 3天前开始出现胸痛...
既往史: 高血压10年,糖尿病5年
```

### 步骤 3: 触发识别

1. 点击"从屏幕获取患者信息"按钮
2. 系统会自动执行以下步骤:
   - ✅ 检查后端服务 (1秒)
   - ✅ 截取屏幕 (0.5秒)
   - ✅ 上传图像 (0.5秒)
   - ✅ AI识别患者信息 (15-20秒) ← **最耗时**
   - ✅ 显示识别结果

### 步骤 4: 查看识别结果

识别完成后,系统会显示:
- 患者基本信息(姓名、年龄、性别、患者ID)
- 就诊信息(科室、主诉、诊断)
- 识别置信度

**置信度说明**:
- 🟢 高 (≥80%): 识别准确,可直接使用
- 🟡 中 (60-80%): 建议核对
- 🔴 低 (<60%): 需要仔细检查并手动修正

### 步骤 5: 编辑和确认

1. 如果识别有误,点击"编辑"按钮
2. 手动修正错误的字段
3. 点击"保存"
4. 点击"确认并获取推荐"

### 步骤 6: 查看检查推荐

系统会基于患者信息生成检查项目推荐,包括:
- 检查项目名称
- 检查类型和部位
- 优先级(高/中/低)
- 推荐理由
- 预估费用

您可以:
- 点击"采纳"或"不采纳"提供反馈
- 点击"打印"打印推荐列表
- 点击"导出"导出为文本文件

## ⚠️ 常见问题

### 问题 1: 后端服务未运行

**症状**: 点击按钮后提示"后端服务未运行"

**解决方案**:
```bash
cd desktop-ai-assistant/backend-service
python -m app.main
```

### 问题 2: 识别超时

**症状**: 识别过程超过60秒未响应

**原因**: 
- Ollama 服务未运行
- 模型未加载
- 系统资源不足

**解决方案**:
```bash
# 检查 Ollama
curl http://localhost:11434/api/tags

# 重启 Ollama
brew services restart ollama

# 检查系统资源
top
```

### 问题 3: 识别准确率低

**症状**: 置信度 < 60%,多个字段识别错误

**原因**:
- 截图不清晰
- 患者信息格式不规范
- 字体太小或模糊

**解决方案**:
1. 放大患者信息区域
2. 确保文字清晰可见
3. 使用标准格式显示患者信息
4. 手动编辑识别结果

### 问题 4: 推荐生成失败

**症状**: 确认患者信息后,推荐生成失败

**原因**:
- 患者姓名为空
- 后端API错误
- 网络超时

**解决方案**:
1. 确保患者姓名已填写
2. 检查后端日志
3. 重试操作

# 屏幕捕获患者信息识别功能

## 功能概述

本功能实现了通过屏幕截图自动识别医生工作页面中的患者信息,并基于AI生成检查项目推荐的完整流程。

## 技术架构

```
医生工作页面 (medical-integration-system)
    ↓ 显示患者信息
    
桌面AI助手 (desktop-ai-assistant)
    ↓ 屏幕截图 (Electron desktopCapturer)
    ↓ OCR识别 (Electron API)
    ↓ AI提取患者信息 (Deepseek API)
    
后端服务 (backend-service)
    ↓ AI推荐引擎 (Deepseek API)
    
客户端展示 (desktop-ai-assistant)
    ↓ 显示推荐结果
```

## 实现的功能

### 1. 前端组件

#### PatientInfoCapture (患者信息捕获组件)
- **位置**: `desktop-ai-assistant/src/renderer/components/medical/PatientInfoCapture.tsx`
- **功能**:
  - 触发屏幕截图
  - 显示截图预览
  - 显示OCR识别进度
  - 调用后端API提取患者信息
  - 错误处理和重试机制

#### PatientInfoDisplay (患者信息展示组件)
- **位置**: `desktop-ai-assistant/src/renderer/components/medical/PatientInfoDisplay.tsx`
- **功能**:
  - 卡片式展示患者基本信息
  - 支持手动编辑和修正
  - 显示识别置信度
  - 低置信度警告提示
  - 确认并获取推荐按钮

#### ExamRecommendations (检查推荐展示组件)
- **位置**: `desktop-ai-assistant/src/renderer/components/medical/ExamRecommendations.tsx`
- **功能**:
  - 列表展示推荐的检查项目
  - 显示优先级(高/中/低)
  - 显示推荐理由和预估费用
  - 支持采纳/不采纳反馈
  - 支持打印和导出

### 2. 服务层

#### PatientInfoExtractor (患者信息提取服务)
- **位置**: `desktop-ai-assistant/src/services/patient-info-extractor.ts`
- **功能**:
  - 从OCR文本中提取患者信息
  - 支持AI辅助提取和规则提取两种模式
  - 字段识别:姓名、年龄、性别、患者ID、科室、主诉、诊断
  - 置信度评估
  - 数据验证

### 3. 后端API

#### AI服务扩展
- **位置**: `desktop-ai-assistant/backend-service/app/services/ai_service.py`
- **新增方法**:
  - `extract_patient_info()`: 从OCR文本提取患者信息
  - 使用Deepseek API进行智能提取
  - 返回结构化的患者信息JSON

#### API路由

##### 患者信息提取接口
- **端点**: `POST /api/ai/extract-patient-info`
- **位置**: `desktop-ai-assistant/backend-service/app/api/ai_chat.py`
- **请求体**:
  ```json
  {
    "text": "OCR识别的文本",
    "screenshot": "base64图片数据(可选)"
  }
  ```
- **响应体**:
  ```json
  {
    "success": true,
    "patient_info": {
      "name": "张三",
      "age": 45,
      "gender": "男",
      "patientId": "P001",
      "department": "呼吸内科",
      "chiefComplaint": "胸痛3天",
      "diagnosis": "疑似肺炎",
      "confidence": 0.85
    }
  }
  ```

##### 屏幕捕获推荐接口
- **端点**: `POST /api/recommendations/from-screen-capture`
- **位置**: `desktop-ai-assistant/backend-service/app/api/recommendations.py`
- **请求体**:
  ```json
  {
    "patient_info": {
      "name": "张三",
      "age": 45,
      "gender": "男",
      "chief_complaint": "胸痛3天",
      "medical_history": "高血压病史"
    }
  }
  ```
- **响应体**:
  ```json
  {
    "success": true,
    "visit_id": 123,
    "recommendations": [
      {
        "id": 1,
        "title": "胸部CT",
        "exam_type": "CT",
        "body_part": "胸部",
        "priority": "high",
        "reason": "根据主诉胸痛,需要排查肺部疾病",
        "urgency": "急诊",
        "estimated_cost": "300-500元",
        "confidence": 0.9
      }
    ]
  }
  ```

# OCR方案 vs 视觉模型方案对比分析

## 执行摘要

**推荐方案**: **方案B - 直接视觉识别 (Qwen2.5-VL)**

**核心理由**:
1. ✅ 更高的准确率 (86% vs 81%)
2. ✅ 更好的隐私保护 (100%本地 vs 云端API)
3. ✅ 零运行成本 (vs $12-120/年)
4. ✅ 更简单的架构 (减少一个处理步骤)
5. ✅ 更好的上下文理解能力

**代码修改**: 需要少量修改,主要是将模型名称从 `llama3.2-vision` 改为 `qwen2.5vl:latest`

---
