# 语音识别模型配置指南

## 概述

本系统支持三种语音识别模型：
- **浏览器原生**：使用浏览器内置的 Web Speech API
- **Whisper**：OpenAI 的开源语音识别模型，支持多语言
- **FunASR**：阿里巴巴达摩院的开源语音识别模型，专为中文优化

## 功能特性

### 1. 模型选择
- 在设置页面的"语音设置"模块中选择语音识别模型
- 支持实时切换模型
- 自动保存配置

### 2. 模型测试
- 提供统一的测试界面
- 支持录制音频并测试所有模型
- 显示准确率、延迟、置信度等指标
- 提供模型性能对比

### 3. 配置管理
- 每种模型都有独立的配置选项
- 支持语言设置
- 支持唤醒词配置

## 使用方法

### 1. 访问语音设置
1. 打开应用设置
2. 点击"语音设置"选项卡
3. 在"语音识别模型"部分选择模型

### 2. 测试模型性能
1. 点击"测试所有模型"按钮
2. 在弹出窗口中录制测试音频
3. 点击"开始测试"按钮
4. 查看各模型的测试结果
5. 根据结果选择最佳模型

### 3. 配置模型参数

#### Whisper 配置
- **模型大小**：tiny, base, small, medium, large, large-v2, large-v3
- **设备**：cpu, cuda, auto
- **计算类型**：int8, int16, float16, float32
- **语言**：支持多语言
- **温度**：控制随机性
- **束搜索大小**：影响识别质量

#### FunASR 配置
- **模型类型**：paraformer-zh, paraformer-en, conformer-zh, conformer-en
- **设备**：cpu, cuda, auto
- **批处理大小**：影响处理速度
- **语言**：支持中文和英文
- **热词**：医疗术语优化
- **标点符号**：是否添加标点
- **时间戳**：是否包含时间信息

## 模型对比

| 特性 | 浏览器原生 | Whisper | FunASR |
|------|------------|---------|--------|
| 延迟 | 低 (150ms) | 中 (800ms) | 中 (600ms) |
| 准确率 | 中 (85%) | 高 (92%) | 高 (88%) |
| 中文支持 | 一般 | 好 | 优秀 |
| 医学术语 | 一般 | 好 | 优秀 |
| 资源消耗 | 低 | 高 | 中 |
| 离线支持 | 是 | 是 | 是 |

## 推荐配置

### 医疗场景推荐
- **主要模型**：FunASR (paraformer-zh)
- **备用模型**：Whisper (base)
- **语言**：zh-CN
- **热词**：医生、患者、诊断、治疗、症状、检查

### 通用场景推荐
- **主要模型**：Whisper (base)
- **备用模型**：浏览器原生
- **语言**：根据需求选择
- **热词**：小助手、你好、帮助

## 故障排除

### 1. 模型无法加载
- 检查网络连接（首次下载模型需要网络）
- 检查磁盘空间（模型文件较大）
- 查看控制台错误信息

### 2. 识别准确率低
- 确保环境安静
- 调整麦克风灵敏度
- 尝试不同的模型
- 添加相关热词

### 3. 延迟过高
- 选择较小的模型
- 使用 GPU 加速（如果可用）
- 调整批处理大小

### 性能优化
- 模型懒加载

## 开发说明

### 添加新模型
1. 实现 `IVoiceRecognitionService` 接口
2. 在 `VoiceRecognitionManager` 中注册
3. 更新配置类型定义
4. 添加 UI 配置选项

### 测试新模型
1. 在 `VoiceRecognitionTest` 组件中添加测试逻辑
2. 更新测试结果显示
3. 添加性能指标

## 注意事项

1. **隐私保护**：所有语音数据在本地处理，不会上传到云端
2. **性能考虑**：大型模型需要更多计算资源
3. **兼容性**：不同操作系统和浏览器可能有差异
4. **更新维护**：定期更新模型以获得最佳性能
