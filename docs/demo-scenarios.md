## 二、核心演示场景

### 场景1: 智能患者查询 🔍

**场景描述**: 医生需要快速查询患者信息

**演示步骤**:

1. **启动状态**
   - Medical Integration System 显示患者列表
   - Desktop AI Assistant 浮动窗口收起状态,显示在屏幕右下角

2. **触发助手**
   - 用户点击浮动窗口
   - 浮动窗口展开,显示快速操作面板

3. **智能识别**
   - 助手自动检测到Medical Integration System
   - 浮动窗口显示智能建议:
     ```
     💡 智能建议
     ┌───────────────────────────────┐
     │ 检测到RIS系统                 │
     │ 当前页面: 患者列表            │
     │ [快速查询患者] [查看工作列表] │
     └───────────────────────────────┘
     ```

4. **语音查询**
   - 用户点击浮动窗口的语音按钮
   - 语音窗口打开,全屏半透明遮罩
   - 用户说: "查询患者张三的检查记录"
   - 实时显示语音识别结果
   - 置信度: 95%

5. **AI处理**
   - 显示"AI正在思考..."动画
   - AI分析语音内容,提取关键信息:
     - 患者姓名: 张三
     - 操作类型: 查询检查记录

6. **执行操作**
   - 助手调用Medical Integration System API
   - 查询患者"张三"的信息
   - 在浮动窗口显示结果:
     ```
     📋 查询结果
     ┌───────────────────────────────┐
     │ 患者: 张三 (P20240115001)     │
     │ 年龄: 45岁  性别: 男          │
     │ 病历号: MRN001                │
     │                               │
     │ 检查记录:                     │
     │ • CT检查 - 胸部 (待报告)      │
     │   2024-01-15 09:30            │
     │                               │
     │ [查看详情] [生成报告]         │
     └───────────────────────────────┘
     ```

7. **后续操作**
   - 用户点击"查看详情"
   - Medical Integration System 自动跳转到患者详情页
   - 浮动窗口自动收起

**演示亮点**:
- ✨ 语音交互流畅自然
- ✨ 智能识别当前场景
- ✨ 自动调用医疗系统API
- ✨ 结果展示清晰直观

---

### 场景2: 桌面内容识别与分析 📸

**场景描述**: 医生在查看患者信息时,需要快速提取屏幕上的关键数据

**演示步骤**:

1. **准备状态**
   - Medical Integration System 显示患者详情页
   - 页面包含患者ID、姓名、检查类型等信息

2. **快速截图**
   - 用户按下全局快捷键: `Cmd+Shift+A`
   - 屏幕变暗,进入截图模式
   - 显示提示: "拖拽选择要分析的区域"

3. **选择区域**
   - 用户拖拽选择患者信息区域
   - 选择框实时显示尺寸
   - 释放鼠标后,开始OCR识别

4. **实时OCR**
   - 显示识别进度: "正在识别... 50%"
   - 实时显示识别结果:
     ```
     实时OCR预览:
     ┌─────────────────────────────┐
     │ 患者ID: P20240115001        │
     │ 姓名: 张三                  │
     │ 年龄: 45岁                  │
     │ 性别: 男                    │
     │ 检查类型: CT检查            │
     │ 部位: 胸部                  │
     └─────────────────────────────┘
     
     识别置信度: 92%
     ```

5. **智能分析**
   - AI自动分析识别结果
   - 识别出关键医疗信息:
     - 患者ID: P20240115001
     - 检查类型: CT检查
     - 部位: 胸部
   
6. **智能建议**
   - 显示可执行的操作:
     ```
     💡 智能建议
     ┌─────────────────────────────┐
     │ 检测到患者检查信息          │
     │                             │
     │ 您可以:                     │
     │ [查询历史检查]              │
     │ [生成报告模板]              │
     │ [查看PACS图像]              │
     │ [复制患者ID]                │
     └─────────────────────────────┘
     ```

7. **一键操作**
   - 用户点击"生成报告模板"
   - 助手自动:
     1. 获取患者信息
     2. 获取检查详情
     3. 生成报告模板
     4. 在Medical Integration System中打开报告编辑器
     5. 自动填充基本信息

**演示亮点**:
- ✨ 全局快捷键快速触发
- ✨ 实时OCR识别
- ✨ 智能分析医疗信息
- ✨ 一键执行复杂操作

### 场景3: 报告编写助手 📝

**场景描述**: 医生在编写影像报告时,需要AI辅助生成诊断建议

**演示步骤**:

1. **打开报告编辑器**
   - Medical Integration System 显示报告编辑页面
   - 已填充患者基本信息和检查信息

2. **唤醒助手**
   - 用户说出唤醒词: "Hey Assistant"
   - 浮动窗口显示唤醒成功动画
   - 语音窗口自动打开

3. **语音输入**
   - 用户说: "帮我生成胸部CT报告的诊断建议"
   - 实时显示识别文字
   - 识别完成后显示确认界面

4. **上下文分析**
   - AI分析当前页面内容
   - 识别出:
     - 当前在报告编辑器
     - 检查类型: 胸部CT
     - 患者信息: 张三, 45岁, 男
   
5. **生成建议**
   - 显示"AI正在生成诊断建议..."
   - 使用打字机效果逐字显示:
     ```
     📋 诊断建议
     
     根据胸部CT检查结果,建议关注以下方面:
     
     1. 肺部情况:
        - 观察肺野是否清晰
        - 检查是否有结节或肿块
        - 评估肺纹理是否正常
     
     2. 纵隔情况:
        - 检查纵隔是否居中
        - 观察淋巴结是否肿大
     
     3. 胸膜情况:
        - 检查是否有胸腔积液
        - 观察胸膜是否增厚
     
     [插入报告] [修改建议] [重新生成]
     ```

6. **插入报告**
   - 用户点击"插入报告"
   - 助手通过API将内容插入到报告编辑器
   - 显示成功提示

7. **继续对话**
   - 用户可以继续提问: "这个患者有什么需要特别注意的吗?"
   - AI基于患者信息和检查类型给出建议

**演示亮点**:
- ✨ 语音唤醒自然流畅
- ✨ 上下文感知能力强
- ✨ 生成内容专业准确
- ✨ 无缝集成到工作流

### 场景4: 多任务协同工作 🔄

**场景描述**: 医生同时处理多个患者的检查,需要快速切换和管理

**演示步骤**:

1. **工作列表**
   - Medical Integration System 显示待处理检查列表
   - 有3个待报告的检查

2. **打开主窗口**
   - 用户双击浮动窗口
   - 主窗口打开,显示完整功能

3. **医疗系统Tab**
   - 切换到"医疗系统"Tab
   - 显示与Medical Integration System同步的工作列表:
     ```
     🏥 我的工作列表
     
     待报告 (3)
     ┌─────────────────────────────────┐
     │ 张三 - CT检查 - 胸部            │
     │ 2024-01-15 09:30  [开始报告]   │
     ├─────────────────────────────────┤
     │ 李四 - MRI检查 - 头部           │
     │ 2024-01-15 10:00  [开始报告]   │
     ├─────────────────────────────────┤
     │ 王五 - X光检查 - 腰椎           │
     │ 2024-01-15 10:30  [开始报告]   │
     └─────────────────────────────────┘
     ```

4. **智能排序**
   - 用户点击"智能排序"
   - AI根据优先级、等待时间、检查类型等因素重新排序
   - 显示排序理由

5. **批量操作**
   - 用户选择多个检查
   - 点击"批量生成报告模板"
   - 助手依次为每个检查生成模板
   - 显示进度: "正在处理 2/3..."

6. **实时同步**
   - 在Medical Integration System中的操作实时同步到助手
   - 在助手中的操作也实时反映到Medical Integration System
   - 显示同步状态指示器

**演示亮点**:
- ✨ 工作列表实时同步
- ✨ 智能排序和优先级管理
- ✨ 支持批量操作
- ✨ 双向实时同步

**演示步骤**:

1. **打开设置**
   - 用户在主窗口切换到"设置"Tab
   - 显示个性化设置选项

2. **工作习惯分析**
   - 显示使用统计:
     ```
     📊 使用统计
     
     最常用功能:
     1. 患者查询 (45%)
     2. 报告生成 (30%)
     3. 桌面识别 (15%)
     4. 语音交互 (10%)
     
     工作时段:
     • 高峰: 09:00-12:00, 14:00-17:00
     • 平均每天使用: 3.5小时
     
     效率提升:
     • 报告编写时间减少: 35%
     • 患者查询速度提升: 60%
     ```

3. **个性化建议**
   - AI根据使用习惯提供建议:
     ```
     💡 个性化建议
     
     根据您的使用习惯,我们建议:
     
     1. 将"患者查询"添加到浮动窗口快速操作
     2. 设置"报告生成"的快捷键为 Cmd+R
     3. 在09:00-12:00自动启用专注模式
     4. 启用智能提醒功能
     
     [应用建议] [自定义]
     ```

4. **快捷键自定义**
   - 用户自定义常用操作的快捷键
   - 实时预览快捷键效果
   - 检测快捷键冲突

5. **语音指令训练**
   - 用户可以添加自定义语音指令
   - 例如: "打开今天的工作列表" → 打开当天的检查列表
   - 支持语音指令的测试和调试

**演示亮点**:
- ✨ 智能学习用户习惯
- ✨ 提供个性化建议
- ✨ 支持高度自定义
- ✨ 持续优化用户体验

## 三、演示流程建议

### 3.1 完整演示流程 (15分钟)

**时间分配**:
- 0-2分钟: 介绍背景和演示环境
- 2-5分钟: 场景1 - 智能患者查询
- 5-8分钟: 场景2 - 桌面内容识别
- 8-11分钟: 场景3 - 报告编写助手
- 11-13分钟: 场景4 - 多任务协同
- 13-15分钟: 总结和Q&A

**演示脚本**:

```
[开场]
"大家好,今天我要展示的是Desktop AI Assistant,
一个专为医疗工作者设计的智能桌面助手。

它的设计理念是'不打扰、隐身、谁叫谁出',
让AI助手真正融入医生的日常工作流程。

现在,让我们看看它如何帮助医生提高工作效率..."

[场景1演示]
"首先,让我们看看最常见的场景 - 查询患者信息。

医生正在查看患者列表,需要快速查询某个患者的检查记录。

传统方式需要在系统中逐层点击,非常繁琐。

现在,医生只需要点击屏幕角落的助手图标,
然后用语音说出需求...

[演示操作]

看,助手立即理解了医生的需求,
自动查询并展示了患者的完整信息。

整个过程不到5秒钟,大大提高了效率。"

[继续其他场景...]

[结尾]
"通过这些演示,我们可以看到Desktop AI Assistant
如何真正理解医生的工作场景,
提供智能、便捷、高效的辅助服务。

它不仅仅是一个工具,更是医生的智能工作伙伴。

谢谢大家!"
```

### 3.2 快速演示流程 (5分钟)

**聚焦核心功能**:
1. 语音查询患者 (2分钟)
2. 桌面识别+一键操作 (2分钟)
3. 总结 (1分钟)

### 3.3 深度演示流程 (30分钟)

**包含所有场景**:
- 所有5个核心场景
- 详细的功能讲解
- 技术架构介绍
- 现场Q&A
