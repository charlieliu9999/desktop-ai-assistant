# 网络搜索功能设置指南

## 概述

您的 AI 助手现在支持网络搜索功能！这意味着 AI 可以搜索网络获取最新信息来回答您的问题。

## 功能特点

- 🔍 **多种搜索提供商**：支持 Google、Bing、DuckDuckGo、SerpAPI 等
- 🆓 **免费选项**：DuckDuckGo 无需 API Key 即可使用
- 🤖 **智能工具调用**：AI 会在需要时自动搜索网络
- ⚙️ **灵活配置**：可自定义搜索参数、语言、地区等

## 快速开始

### 1. 启用网络搜索

1. 打开 AI 助手设置面板
2. 点击左侧的 "网络搜索" 选项
3. 勾选 "启用网络搜索功能"
4. 勾选 "启用工具调用"

### 2. 选择搜索提供商

#### 选项 1：DuckDuckGo（推荐，免费）
- 无需 API Key
- 直接可用
- 适合日常使用

#### 选项 2：Google Custom Search
1. 访问 [Google Custom Search](https://cse.google.com/cse/)
2. 创建新的搜索引擎
3. 获取 API Key 和搜索引擎 ID
4. 在设置中填入相关信息

#### 选项 3：Bing Search API
1. 访问 [Azure 认知服务](https://azure.microsoft.com/services/cognitive-services/bing-web-search-api/)
2. 创建 Bing Search API 资源
3. 获取 API Key
4. 在设置中填入 API Key

#### 选项 4：SerpAPI
1. 访问 [SerpAPI](https://serpapi.com/)
2. 注册账户并获取 API Key
3. 在设置中填入 API Key

## 配置说明

### 基本设置
- **最大结果数**：每次搜索返回的结果数量（1-20）
- **语言**：搜索结果的显示语言
- **地区**：搜索结果的地区偏好
- **安全搜索**：是否过滤不适当内容

### 高级设置
- **超时时间**：搜索请求的超时时间（毫秒）
- **重试次数**：搜索失败时的重试次数
- **速率限制**：每分钟最大请求数

## 使用方法

### 自动搜索
当您询问需要最新信息的问题时，AI 会自动调用网络搜索：

```
用户：今天北京的天气怎么样？
AI：[自动搜索] 根据最新搜索结果，今天北京...
```

### 手动搜索
您也可以直接要求 AI 搜索特定信息：

```
用户：请搜索最新的 AI 技术发展趋势
AI：[执行搜索] 根据搜索结果...
```

## 支持的查询类型

- 📰 **新闻资讯**：最新新闻、事件
- 🌤️ **实时数据**：天气、股价、汇率
- 📊 **统计数据**：人口、经济数据
- 🔬 **技术信息**：最新技术、产品发布
- 📚 **学术信息**：研究论文、学术动态

## 注意事项

1. **模型要求**：需要支持工具调用的 AI 模型（如 qwen3、llama3.2 等）
2. **网络连接**：需要稳定的网络连接
3. **API 限制**：付费服务可能有使用限制
4. **隐私保护**：搜索查询会发送到相应的搜索服务

## 故障排除

### 搜索不工作
1. 检查网络连接
2. 确认已启用网络搜索和工具调用
3. 验证 API Key（如果使用付费服务）
4. 查看日志文件了解详细错误

### 结果不准确
1. 尝试调整搜索语言和地区设置
2. 使用更具体的关键词
3. 考虑切换到不同的搜索提供商

### 性能问题
1. 减少最大结果数
2. 增加超时时间
3. 检查网络速度

## 技术细节

### 工具调用机制
AI 模型通过工具调用机制自动决定何时需要搜索网络：

```json
{
  "type": "function",
  "function": {
    "name": "web_search",
    "description": "搜索网络获取最新信息",
    "parameters": {
      "query": "搜索关键词",
      "maxResults": 5
    }
  }
}
```

### 支持的搜索提供商 API
- **DuckDuckGo**：Instant Answer API
- **Google**：Custom Search JSON API
- **Bing**：Web Search API v7
- **SerpAPI**：Google Search Results API
