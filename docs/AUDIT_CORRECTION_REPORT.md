## ✅ 纠正措施

### 1. 修复OCR服务Bug

**问题**: OCR服务返回负数置信度，导致Pydantic验证失败

**修复**:
```python
# 修复前
confidences = [
    float(conf) for conf in data["conf"] if conf != "-1" and conf != ""
]
avg_confidence = (
    sum(confidences) / len(confidences) / 100.0 if confidences else 0.0
)

# 修复后
confidences = [
    float(conf) for conf in data["conf"] 
    if conf != "-1" and conf != "" and float(conf) >= 0
]
avg_confidence = (
    sum(confidences) / len(confidences) / 100.0 if confidences else 0.0
)
# 确保置信度在有效范围内
avg_confidence = max(0.0, min(1.0, avg_confidence))
```

**结果**: OCR服务测试从0/8通过提升到8/8通过(100%)
