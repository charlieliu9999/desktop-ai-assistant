## 🔍 问题分析

### 发现的问题

用户反馈在设置中看不到新的主题设置页面，仍然是旧的下拉选择主题方案。

### 根本原因

项目中存在两个设置界面：

1. **`SettingsWindow.tsx`** - 独立的设置窗口（未被使用）
   - 路径：`src/renderer/pages/SettingsWindow.tsx`
   - 我之前将`ThemeSettings`组件集成到了这里
   - 但用户实际看不到这个窗口

2. **`SettingsPanel.tsx`** - 主窗口中的设置面板（实际使用的）
   - 路径：`src/renderer/components/SettingsPanel.tsx`
   - 这是用户实际看到的设置界面
   - 包含旧的主题下拉选择器

---

## ✅ 解决方案

### 1. 集成ThemeSettings到SettingsPanel

**修改文件**: `src/renderer/components/SettingsPanel.tsx`

#### 步骤1: 导入ThemeSettings组件

```typescript
import { ThemeSettings } from './ThemeSettings';
```

#### 步骤2: 添加theme到SettingsSection类型

```typescript
type SettingsSection = 'general' | 'theme' | 'voice' | 'ai' | ...;
```

#### 步骤3: 在侧边栏菜单中添加主题设置选项

```typescript
const sections = [
  { id: 'general' as SettingsSection, name: '常规设置', icon: Settings },
  { id: 'theme' as SettingsSection, name: '主题设置', icon: Activity }, // 新增
  { id: 'voice' as SettingsSection, name: '语音设置', icon: Volume2 },
  // ...
];
```

#### 步骤4: 在renderContent中添加theme的case

```typescript
const renderContent = () => {
  switch (activeSection) {
    case 'general':
      return renderGeneralSettings();
    case 'theme':
      return <ThemeSettings />; // 新增
    case 'voice':
      return renderVoiceSettings();
    // ...
  }
};
```

#### 步骤5: 移除常规设置中的旧主题选择器

将原来的主题下拉选择器和玻璃效果滑块（约106行代码）替换为提示信息：

```tsx
<div className="p-4 bg-blue-50 dark:bg-blue-900/20 border border-blue-200 dark:border-blue-800 rounded-lg">
  <p className="text-sm text-blue-700 dark:text-blue-300">
    💡 主题和玻璃效果设置已移至"主题设置"页面，请点击左侧菜单中的"主题设置"进行配置。
  </p>
</div>
```
