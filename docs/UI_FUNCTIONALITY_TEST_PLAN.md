## 详细测试用例

### 一、AI设置测试

#### 1.1 后端Provider列表加载
**测试步骤**:
1. 打开设置面板
2. 切换到"AI设置"标签
3. 检查是否显示provider列表

**API调用**: `GET /v1/ai/providers`

**预期结果**:
- 显示可用的provider列表(openai, deepseek, dashscope, local)
- 每个provider显示状态(可用/不可用)

#### 1.2 模型列表加载
**测试步骤**:
1. 选择一个provider
2. 检查是否显示该provider的模型列表

**API调用**: `GET /v1/ai/models`

**预期结果**:
- 显示该provider支持的模型列表
- 模型名称正确

#### 1.3 模型测试
**测试步骤**:
1. 选择一个模型
2. 点击"测试连接"按钮
3. 查看测试结果

**API调用**: `POST /v1/ai/test`

**预期结果**:
- 显示测试进度
- 成功: 显示✅和响应时间
- 失败: 显示❌和错误信息

#### 1.4 场景配置
**测试步骤**:
1. 打开"模型配置"面板
2. 选择场景(ai_chat, ai_chat_aliyun等)
3. 查看场景配置
4. 修改配置并保存

**API调用**: 
- `GET /v1/config/scenarios`
- `GET /v1/config/scenarios/{scenario}`
- `PUT /v1/config/scenarios/{scenario}`

**预期结果**:
- 显示所有可用场景
- 显示场景的当前配置
- 保存成功后显示提示
