## 后端 API 测试

### 1. 登录接口

```bash
curl -X POST http://localhost:8010/api/bisheng/login \
  -H "Content-Type: application/json" \
  -d '{"username":"test","password":"test123"}'
```

- [ ] 验证返回 200 状态码
- [ ] 验证返回包含 token
- [ ] 验证返回包含 expiry

### 2. 工作流列表接口

```bash
curl http://localhost:8010/api/bisheng/workflows?page_size=10 \
  -H "Authorization: Bearer YOUR_TOKEN"
```

- [ ] 验证返回 200 状态码
- [ ] 验证返回工作流数组
- [ ] 验证工作流包含必要字段

### 3. 工作流调用接口(非流式)

```bash
curl -X POST http://localhost:8010/api/bisheng/workflow/invoke \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "workflow_id": "xxx",
    "input": {"question": "你好"},
    "stream": false
  }'
```

- [ ] 验证返回 200 状态码
- [ ] 验证返回完整响应

### 4. 工作流调用接口(流式)

```bash
curl -X POST http://localhost:8010/api/bisheng/workflow/invoke \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "workflow_id": "xxx",
    "input": {"question": "你好"},
    "stream": true
  }'
```

- [ ] 验证返回 200 状态码
- [ ] 验证 Content-Type 为 text/event-stream
- [ ] 验证流式数据格式正确

### 5. 配置接口

```bash
# 获取配置
curl http://localhost:8010/api/bisheng/config

# 更新配置
curl -X POST http://localhost:8010/api/bisheng/config \
  -H "Content-Type: application/json" \
  -d '{"enabled": true}'
```

- [ ] 验证获取配置成功
- [ ] 验证更新配置成功
- [ ] 验证配置不包含敏感信息

### 6. 状态接口

```bash
curl http://localhost:8010/api/bisheng/status
```

- [ ] 验证返回服务状态
- [ ] 验证连接状态正确
- [ ] 验证认证状态正确
