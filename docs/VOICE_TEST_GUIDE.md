## 性能基准

### 录音性能
- 开始录音延迟: < 500ms
- 停止录音到数据就绪: < 200ms
- 录音文件大小: 约 2-3 KB/秒

### 播放性能
- 点击播放到开始播放: < 500ms
- WebM 直接播放: 优先使用
- WAV 转换时间: < 1秒（如果需要）

### 资源使用
- 内存增长: < 5MB (连续 10 次播放)
- AudioContext 数量: 始终为 0（已关闭）
- MediaStream 数量: 录音时 1 个，停止后 0 个

## 常见问题排查

### 问题 1: 播放没有声音
**检查**:
1. 系统音量是否打开
2. 浏览器音频是否被禁用
3. 查看控制台是否有错误

### 问题 2: 录音权限被拒绝
**解决**:
1. 系统设置 → 隐私与安全 → 麦克风
2. 确保 Electron 有麦克风权限
3. 重启应用

### 问题 3: 音频格式不支持
**检查**:
```javascript
// 在控制台执行
navigator.mediaDevices.getSupportedConstraints()
```
