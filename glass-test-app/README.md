# 玻璃效果测试应用

这是一个独立的 Electron 桌面应用,用于测试玻璃效果(Glassmorphism)。

## 🎯 功能特点

- ✅ **透明窗口**: 窗口背景完全透明,可以看到桌面
- ✅ **玻璃效果**: 使用 `backdrop-filter: blur()` 实现毛玻璃效果
- ✅ **无边框**: 无系统边框,完全自定义UI
- ✅ **置顶显示**: 窗口始终在最前面
- ✅ **可拖拽**: 可以拖动窗口到任意位置

## 📦 安装步骤

### 1. 安装依赖

```bash
cd desktop-ai-assistant/glass-test-app
npm install
```

或者使用 pnpm:

```bash
cd desktop-ai-assistant/glass-test-app
pnpm install
```

### 2. 运行应用

```bash
npm start
```

或者:

```bash
pnpm start
```

## 🎨 如何验证玻璃效果

1. **启动应用后**,你会看到一个浮动窗口出现在桌面上
2. **移动窗口**到不同的位置(拖拽窗口即可)
3. **观察背景**:
   - 窗口背景应该是**半透明**的
   - 能看到**桌面背景**透过窗口
   - 背景应该是**模糊**的,不是清晰的
   - 移动窗口时,背后的内容应该跟随变化

## 🔍 玻璃效果参数

当前使用的玻璃效果参数:

```css
background: rgba(255, 255, 255, 0.15);  /* 15% 不透明度 */
backdrop-filter: blur(40px) saturate(200%);  /* 40px 模糊 + 200% 饱和度 */
```

## 💡 提示

- **关闭窗口**: 点击右上角的红色 × 按钮
- **拖动窗口**: 在窗口的任意空白区域按住鼠标拖动
- **调整大小**: 窗口可以调整大小(拖动边缘)

## 🐛 故障排除

### 如果看不到玻璃效果:

1. **检查操作系统**:
   - macOS: 完全支持
   - Windows 10/11: 完全支持
   - Linux: 部分支持(取决于桌面环境)

2. **检查 Electron 版本**:
   - 确保使用 Electron 28 或更高版本

3. **检查系统设置**:
   - Windows: 确保"透明效果"已启用
   - macOS: 确保"减少透明度"未启用

### 如果窗口无法拖动:

- 确保在窗口的空白区域拖动,而不是在按钮或输入框上

## 📝 技术细节

- **框架**: Electron 28
- **透明窗口**: `transparent: true`
- **无边框**: `frame: false`
- **置顶**: `alwaysOnTop: true`
- **玻璃效果**: CSS `backdrop-filter`
